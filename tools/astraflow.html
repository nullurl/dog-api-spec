星图接入

把星图的对话模型与生图模型接进这座站点：拉模型清单、流式对话、文生图。 生出来的图可以直接牵走 —— 交给《赛博遛狗》降格成网格，再导出 SVG。 本页是本站唯一会出网的页面；其余页面照旧离线可读。

这一页是例外，而且只有这一页。 正文、附录、参考页、其余工具页都不发请求 —— 直接打开就能读，拔掉网线也一样。 本页要调用外部模型，所以必须联网，这就是它唯一的功能。 API KEY 不写进任何文件，只留在你浏览器的内存里；默认连标签页都不记， 除非你自己打开下面那个开关。清单里的价格来自平台的 /v1/models， 本页只做展示与估算，不做结算。

自检

自检只跑纯函数：节点表、鉴权头、两种请求体的构造、模型分类、SSE 解析、 base64 归一、打码与 curl 生成。它不发任何请求，所以断网也能跑。

渠道 —— 注册与算力金

  1. 注册 UCloud 账号并完成实名认证：星图 AstraFlow 活动页。 注册用邮箱，算力券发到邮箱。
  2. 领 50 元算力金：领取入口。
  3. 在控制台的模型服务平台里创建 API Key，粘回上面的「接入配置」。额度与价格以平台页面为准。
上面两条链接由站点维护者提供，带渠道标记。本站不从其中获取任何数据， 也不知道你注册与否、用了多少额度。

已知限制

  • 必须先有 KEY。清单接口免 KEY，但对话与生图接口要鉴权。
  • 浏览器直连要过 CORS。实测 api.modelverse.cn 返回 Access-Control-Allow-Origin: * 并放行 Authorization，所以网页可以直连；但换节点、换代理或平台改策略都会失效，那时看下面贴的 curl。
  • 从 file:// 打开会被浏览器拦。本页只支持 http(s)：线上站点，或本地起一个静态服务。
  • 生图返回的是 base64，图直接进内存，不落盘 —— 除非你点「下载 PNG」。
  • 「送进赛博遛狗」靠同一标签页内的交接：图只在本标签页的会话存储里放一次，遛狗页读完就删。 换了标签页或跳转前刷新过，就只剩下载再拖进去这条路。
  • 价格是清单里的目录价（含峰谷时段说明），不是账单。真实扣费以平台账单为准。
  • 本页不保存对话历史。刷新即清零。
